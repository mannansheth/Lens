# Phase 5 — Grounded answer generation

Answer generation combines retrieved evidence with provider-specific model requests behind a shared interface. Structured responses are checked for supported intent, evidence references, and citation consistency before being presented. Ollama and Gemini are supported answer providers; provider availability and answer quality depend on local configuration and the selected model.

See [retrieval and answer generation](../../current/retrieval.md) and [answer providers](../../current/providers.md).

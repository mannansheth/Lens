# Phase 1 — Foundation and persistence

The foundation supplies the CLI, configuration, project identity, relational persistence, migrations, and the boundaries used by later indexing and retrieval stages. The database stores indexed project data and vectors; Lens does not modify the application being indexed.

See [architecture](../../current/architecture.md), [index storage](../../current/embeddings-and-storage.md), and [setup](../../current/setup.md) for current implementation details.

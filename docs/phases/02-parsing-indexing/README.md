# Phase 2 — Parsing and indexing

The indexing pipeline discovers eligible files, dispatches language-specific parsers, extracts symbols and source locations, builds retrieval documents, generates embeddings, and persists a project snapshot. Markdown and related documentation formats are sectioned by headings so project documentation can be retrieved alongside source code.

See [indexing](../../current/indexing.md) and [embeddings and storage](../../current/embeddings-and-storage.md).

# Phase 6 — Client navigation and database questions

Client mode adds user-facing explanations and structured navigation evidence where source routes, links, or controller actions can be established. The SQL workflow introspects configured databases, generates and validates read-only queries, and requires confirmation before execution. Dynamic route values, authorization, and complete runtime behavior remain responsibilities of the host application.

See [client navigation](../../current/client-navigation.md), [database questions](../../current/database-questions.md), and [implementation status](../../current/mvp-status.md).

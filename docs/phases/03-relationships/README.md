# Phase 3 — Relationships and data flow

Static relationship discovery connects supported constructs such as definitions, references, imports, routes, calls, SQL usage, and selected cross-layer flows. Evidence records retain source locations and confidence; unresolved or ambiguous relationships remain visible rather than being treated as proven runtime behavior.

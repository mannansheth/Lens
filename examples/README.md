# Example fixtures

`demo-app/` is a compact C# and SQL application used for parser and retrieval examples. The separate `questions/demo-app.json` file pairs sample questions with symbols expected in this synthetic fixture.

`fullstack-app/` is a static-analysis fixture spanning JavaScript, C#, Razor, Python, and SQL. Its README explains the relationships it is designed to demonstrate. Neither fixture is a deployable application; Lens parses source and does not start either project.
